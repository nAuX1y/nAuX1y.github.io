# 绿茵王朝 · 交接包 v1.3.11

离线单文件中文足球经理游戏。源码、构建脚本和可运行成品都在本压缩包内。

## 立即运行

- 推荐双击：`dist/grassroots-dynasty.html`（ASCII 文件名，兼容性更好）
- 中文文件名镜像：`dist/绿茵王朝.html`
- 浏览器要求：现代 Edge / Chrome / Firefox / Safari；导出和导入加密存档需要 WebCrypto。iPadOS 26 Safari 已适配存档导入。
- 不需要服务器、不需要联网、不需要 npm。

## 继续开发

```text
src/
  index.html       未打包的页面壳
  styles.css       全部样式
  game.js          全部游戏逻辑（约 9,100 行）
  bundle.py        将 CSS/JS 内联成单文件 HTML
```

构建：

```bash
cd src
python bundle.py
```

默认输出到上一级的 `dist/`。也可以指定输出目录：

```bash
python bundle.py ../dist
```

**不要直接编辑 `dist/*.html`**，它是生成物。修改源码后重新构建。

## 包内文档

- `AI_CONTINUE_PROMPT.md`：可直接交给下一个 AI 的接续开发提示词。
- `HANDOFF.md`：给接手开发者/AI 的架构、状态、注意事项和后续路线。
- `TESTING.md`：构建检查、浏览器烟测、比赛引擎批量模拟脚本、手动验收清单。
- `CHANGELOG.md`：版本变更记录。
- `MANIFEST.txt`：文件大小、SHA-256 与版本信息。
